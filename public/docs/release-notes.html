Release Notes

v0.1.0 — Initial build

First complete pass covering every module in the original specification: authentication & RBAC, user management, multi-currency income/expense tracking with attachments, a customizable dashboard, exportable reports, a fully database-driven settings system, documentation, an initial test suite, and deployment guidance.

Known gaps for a future release: public REST API, 2FA, recurring transactions, budgets/savings goals, OCR receipt scanning, multi-family support — all called out as future work in the original spec and left with schema-level groundwork already in place (see Database Schema).
