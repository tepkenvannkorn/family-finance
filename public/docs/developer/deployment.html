Deployment

Apache vhost

<VirtualHost *:443>
    ServerName finance.example.family
    DocumentRoot /var/www/family-finance-app/public
    <Directory /var/www/family-finance-app/public>
        AllowOverride All
        Require all granted
    </Directory>
    SSLEngine on
    SSLCertificateFile /etc/letsencrypt/live/finance.example.family/fullchain.pem
    SSLCertificateKeyFile /etc/letsencrypt/live/finance.example.family/privkey.pem
</VirtualHost>

File permissions

storage/ must be writable by the web server user (e.g. www-data); everything else can be read-only.

Scheduled exchange rate sync

For "daily" or "weekly" sync, add a cron entry that hits the fetch logic — e.g. a small CLI script wrapping ExchangeRateService::fetchFromApi(), run via 0 6 * * * php /var/www/family-finance-app/cron/sync-exchange-rate.php.

Checklist before going live

  • APP_DEBUG=false in .env
  • force_https enabled in Settings → Security
  • Default admin password changed
  • storage/ and .env confirmed NOT web-accessible (test by visiting their URLs directly)
  • A real backup taken and test-restored at least once
