Coding Standards

  • PSR-12 formatting; declare(strict_types=1) in every file.
  • PDO prepared statements everywhere — never string-concatenated SQL.
  • Controllers stay thin: validation lives in Requests/, authorization in Policies/, business logic in Services/, complex queries in Repositories/.
  • All output goes through View::e() unless deliberately raw (and that's a visible, commented choice).
  • Money is DECIMAL in the database and string-typed in PHP end to end — bcmath for any arithmetic, never floats.
  • New settings are added to the relevant seeder + the SettingsController::SCHEMA array — never hardcoded into a controller.
