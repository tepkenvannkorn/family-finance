Internal API Reference

This app doesn't expose a public REST API (spec §16 lists that as future work), but several endpoints already return JSON for internal AJAX use:

EndpointMethodReturns
/transactions/searchGETHTML fragment (live search results)
/dashboard/dataGETJSON: summary totals + chart series + recent transactions
/dashboard/layoutPOSTJSON body: saves the caller's widget layout

A future public REST API layer would sit alongside these as a new module (e.g. app/Modules/Api), reusing the existing Repositories/Services rather than duplicating query logic.
