FAQ

Can two family members edit the same transaction?

Yes, if you're an administrator, or if it's your own transaction and editing is allowed in Settings.

What happens if I delete a transaction by mistake?

Deleted transactions are kept (soft-deleted) rather than erased immediately, so an administrator can help recover one if needed — ask them.

Why can't I see other family members' transactions?

Only administrators see everyone's transactions and reports. Regular members see only their own — by design.

Can I use the app on my phone?

Yes — it's mobile-responsive and can be added to your home screen like an app.
