Managing Users

Creating a user

Go to Users → + Add user, fill in name/email/role/password, and save. There's no public sign-up — you create every account.

Editing, deactivating, deleting

  • Edit changes name, email, role, or resets the password (leave the password field blank to keep it unchanged).
  • Deactivate blocks sign-in without deleting any of that person's transaction history — the recommended way to "remove" someone.
  • Delete permanently removes the account. Blocked if that person still has recorded transactions — deactivate instead in that case.

Locked accounts

Repeated failed logins temporarily lock an account. You'll see a Locked badge in the Users list — click Unlock to restore access immediately.

You cannot deactivate, delete, or demote the last remaining administrator account — this is a built-in safeguard against locking everyone out.
