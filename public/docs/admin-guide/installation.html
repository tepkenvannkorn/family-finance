Installation

Server requirements

  • PHP 8.3+ with pdo_mysql, bcmath, fileinfo, mbstring extensions
  • Apache 2 with mod_rewrite enabled
  • MySQL 8+
  • Composer

Steps

  1. Copy the application files to your server.
  2. Run composer install in the project root.
  3. Copy config/.env.example to .env and fill in your database credentials and a default admin email/password.
  4. Point your Apache DocumentRoot at the project's public/ folder (see Deployment for a full vhost example).
  5. Run php database/migrate.php to create all tables.
  6. Run php database/seed.php to load default roles, categories, settings, and your admin account.
  7. Visit the site and log in with the admin email/password from your .env.
Change your admin password immediately after first login, from Profile.
