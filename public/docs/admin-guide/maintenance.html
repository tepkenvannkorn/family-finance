Backup & Maintenance

Go to Settings → Backup & maintenance.

Backups

  • Download full database backup (.sql) — a complete mysqldump of everything. Requires the mysqldump binary on the server.
  • Download all transactions (.csv) — just the transaction data, useful for spreadsheets.

Restoring a backup

Restoring isn't done through the web interface (for safety). On the server: mysql -u USER -p family_finance < backup.sql.

Maintenance mode

Turning this on shows every non-administrator a simple "under maintenance" page, while administrators can still sign in normally — useful while you're making changes.

Audit logs

See Audit Logs in the main navigation for a searchable history of every significant action: logins, transaction changes, user management, settings changes, and more.
