Exchange Rates

Go to Settings → Manage exchange rates.

Setting a rate manually

Enter a USD → KHR rate and click Set manually. This is recorded with a timestamp — past reports always use the rate that was current at the time, so changing today's rate never rewrites yesterday's numbers.

Fetching automatically

Click Fetch latest rate now to pull the current rate from an external exchange-rate service. A fetched rate that differs wildly (more than 15%) from the last known rate is rejected automatically, to protect against a bad or tampered response — you'll need to set it manually if that large a change is genuinely correct.

Scheduled sync

Under Settings → Currency, turn on automatic sync and choose an interval (every login, daily, or weekly). See Deployment for wiring the daily/weekly option to a cron job.
